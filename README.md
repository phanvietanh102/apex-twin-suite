## 💡 Why APEX Twin Suite Exists

90% of AI-built projects fail within **30 to 60 days**—not because the LLM couldn't write code or text, but because of **4 Systemic AI Failure Modes**:
1. **The Prompt Ceiling & Sycophancy Trap:** Default AI obeys your prompt blindly, locking the output inside *your* existing blind spots instead of injecting industry unknown-unknowns.
2. **Anchoring vs. Ambiguity:** Existing skills either ask vague open questions (paralyzing beginners) or force 3 narrow multiple-choice options (suppressing a founder's contrarian secret).
3. **Software-Only Myopia:** Popular frameworks (`obra/superpowers`, `BMAD-METHOD`, `github/spec-kit`) are 95% hardcoded for software engineers. They break when applied to **Construction, Real Estate, SEO/AIO, E-Commerce, Invoicing, or Operations**.
4. **Month-2 Architectural Rot:** Hardcoded prices, rules, and prompts get mixed into core logic; historical records get overwritten; and context bloat degrades actual output quality.

### 6 Vũ Khí Cốt Lõi Chỉ Có Ở `APEX Twin Suite v3.5`:

1. **Khai Thác Kép 3 Tầng (Dual-Mode Hybrid Elicitation — Chống Hiệu Ứng Mỏ Neo):**
   * Kết hợp **(1) Câu hỏi mở khai thác "Vũ khí bí mật" của riêng bạn** + **(2) Hỏi xoáy gắt gao vào điểm gãy (như `/grill-me`)** + **(3) Đề xuất sẵn Phương án A/B/C chuẩn ngành kèm Phương án D (Tự do/Tổ hợp)**. Dù bạn *"chưa biết bắt đầu từ đâu"* hay đã có *"ý tưởng đột phá ngoài vùng dự đoán của AI"*, hệ thống đều xử lý hoàn hảo.
2. **Bơm Tri Thức Ngoài Tầm Hiểu Biết (Johari Quadrant 4 + Cộng Thêm 30% Kano Delighters):**
   * Chủ động chỉ ra $\ge 4$ điểm mù chuyên ngành / điểm rò rỉ ngầm và tự động thiết kế thêm **20–30% tính năng thông minh vượt kỳ vọng** (tốn $<20\%$ công sức nhưng nhân $10\times$ giá trị sử dụng).
3. **Hội Đồng 6 Giám Đốc C-Suite Phản Biện Độc Lập (Chống "Vừa Đá Bóng Vừa Thổi Còi"):**
   * Gồm: **CPO (Sản phẩm)**, **CTO (Kiến trúc Hệ thống)**, **VP Domain (Chiến lược Ngành)**, **CFO (Unit Economics)**, **CRO/COO (Rủi ro & Vận hành $<15\text{ phút/ngày}$)** và **Khách hàng Khó tính**.
   * Bắt buộc chạy trên **Model Suy luận Cấp cao** (`Opus/Sonnet Thinking`, `Gemini Pro/Argon High`), tách **Subagent Critic độc lập** để chấm điểm trừ lùi từ 100 (bắt buộc tìm ra $\ge 3$ lỗi thực tế ở vòng đầu và xuất bằng chứng định lượng FMEA / Unit Economics).
4. **Chốt Chặn Kiểm Định Từng Bước (`Gate 1..6`) & Quét Code Thực Thi (`--scan-code`):**
   * Không bao giờ đợi đến bước cuối mới phát hiện bước 2 sai! Script Python kiểm tra từng bước và tự động quét mã nguồn/tài liệu để chặn đứng lỗi làm dối (`TODO`, `FIXME`, dữ liệu giả `mock/stub`), kết hợp chạy kiểm thử tương đương (Behavioral Parity Test).
5. **Cách Ly Ngữ Cảnh Chống Giảm Chất Lượng Output (Zero-Bloat Context Isolation):**
   * Ở bước nào chỉ nạp đúng tài liệu của bước đó. Khi bước vào **Pha 5 (Viết code / Làm sản phẩm)**, AI ngắt toàn bộ văn bản lý thuyết để dành **95% Token & Năng lực suy luận cho chất lượng sản phẩm thực tế**. Có 3 chế độ: `LEAN` (Nhanh gọn), `STANDARD` (Tiêu chuẩn), `DEEP-ENTERPRISE` (Toàn diện).
6. **Bảo Chứng 12 Tháng Không Đập Đi Xây Lại (3-Tier Decoupling & 5-Zone Hygiene):**
   * Tách biệt **Tier A (Lõi bất biến)** — **Tier B (Bảng giá, quy tắc, mẫu câu chỉnh sửa trong 2 phút)** — **Tier C (Giao diện/Xuất file)**.
   * Đóng băng dữ liệu lịch sử (**Red-Zone Snapshot Isolation**: sửa giá tháng sau không bao giờ làm nhảy số hóa đơn/báo giá tháng trước) kèm lộ trình **Day 1 $\rightarrow$ Day 30 $\rightarrow$ Day 90 $\rightarrow$ Day 180 $\rightarrow$ Day 365**.

## 🛠️ 1-Click Installation & Setup (Hướng Dẫn Cài Đặt)

### Option A: Automated 1-Command Installer (Windows / macOS / Linux)

**On Windows (PowerShell):**
```powershell
powershell -ExecutionPolicy Bypass -File .\install-skills.ps1
```

**On macOS / Linux / WSL (Bash):**
```bash
chmod +x ./install-skills.sh && ./install-skills.sh
```
*This automatically installs both `idea-to-product-apex` and `product-workspace-reviewer-apex` into:*
* **Claude Code / Local Skills:** `~/.claude/skills/`
* **Google Antigravity Skills & Global Plugin:** `~/.gemini/config/skills/` & `~/.gemini/config/plugins/idea-to-product-apex/`
* **Workspace Local Skills:** `./.agents/skills/` & `./.claude/skills/`

### Option B: Upload ZIP to Claude Desktop App UI
1. Open **Claude Desktop** $\rightarrow$ **Settings** $\rightarrow$ **Capabilities (or Skills)** $\rightarrow$ **Upload a skill**.
2. Select the pre-packaged ZIP files in [`./dist/`](./dist/):
   * [`dist/idea-to-product-apex-claude-desktop.zip`](./dist/idea-to-product-apex-claude-desktop.zip) *(Greenfield A-to-Z Engine)*
   * [`dist/product-workspace-reviewer-apex-claude-desktop.zip`](./dist/product-workspace-reviewer-apex-claude-desktop.zip) *(Brownfield Review & Upgrade Engine)*

## ⚡ Slash Commands & Quick Triggers

### 🟢 Engine 1: Building a New Idea from A to Z (`idea-to-product-apex`)
* **`/idea-to-product [your idea]`** or **`/apex [your idea]`**: Launch the full 6-Phase pipeline starting with Dual-Mode Discovery.
* **`/apex-lean [your idea]`**: Fast-track Zero-Bloat mode (1 compact spec + immediate verified build).
* **`/apex-redteam`**: Convene the 6-Role C-Suite Council to stress-test your concept.
* **CLI Scaffolder & Gate Auditor:**
  ```bash
  python ./skills/idea-to-product-apex/scripts/init_project.py --dir "./my-project" --name "My Project" --domain "DOM-02"
  python ./skills/idea-to-product-apex/scripts/fitness_audit.py --dir "./my-project" --gate 6 --scan-code "./my-project"
  ```

### 🔵 Engine 2: Reviewing & Upgrading an Existing Product / App / Workspace (`product-workspace-reviewer-apex`)
* **`/review-product [path or description]`** or **`/apex-review`**: Run Forensic X-Ray, C-Suite Before/After Audit, and Strangler-Fig 12M Upgrade.
* **`/audit-workspace`**: Clean up a chaotic folder (`v1`, `v2`, `final_copy`), lock Red-Zone historical records, and reorganize into the 5-Zone Taxonomy without breaking links.
* **CLI Forensic X-Ray Scanner & Review Gate Auditor:**
  ```bash
  python ./skills/product-workspace-reviewer-apex/scripts/xray_scanner.py --dir "./existing-workspace" --name "Existing System" --domain "DOM-04"
  python ./skills/product-workspace-reviewer-apex/scripts/review_gate_audit.py --dir "./existing-workspace" --gate 6 --scan-target "./existing-workspace"
  ```
